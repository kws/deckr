# Deckr Action Runtime rendering proposal for v1

Status: accepted in contract bundle `1.0.0-alpha.3` on 2026-10-20.

The [rendering specification](deckr-action-runtime-rendering.md) now defines the
accepted contract. It covers binding-local support, text and image formats,
optional extensions, output authority and ordering, and dispatch-level results.
Implementation coverage is recorded in the consuming repositories.
